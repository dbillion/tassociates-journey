# tassociates — Legal Journey

> *"Lawyers, ordinary people, and organisations belong at the same table—and move forward together."*

A restrained visual scroll-driven landing page journey for **tassociates**, a premier Nigerian law firm serving local and international clients across cross-border commercial, dispute resolution, and private client matters.

## Live Deployment
🌐 **GitHub Pages:** [https://dbillion.github.io/tassociates-journey/](https://dbillion.github.io/tassociates-journey/)

## Features
- **Scroll World Scrub Engine**: Dynamic camera-flight scrub through three interconnected scenes:
  1. **The Table** — *"All three belong at this table."* (Egalitarian partnership).
  2. **The Hands** — *"We sit beside you, not above you."* (Hands-on cross-border problem solving).
  3. **The Door** — *"Where you go, we walk with you."* (Stepping forward into warm light together).
- **Persistent Accessibility**: Pinned top navigation and mobile floating action button for **"Talk to us"** available at any scroll offset without forcing visitors to complete the animation.
- **Dedicated Information Drawer**:
  - **About Us**: Ethos, Nigerian roots (Victoria Island, Lagos), and cross-border capabilities.
  - **Services Offered**: Corporate governance, arbitration, cross-border FDI, land titles, and private wealth.
  - **Hours & Commitments**: Lagos Chambers (WAT) & International Desks (London/New York) with guaranteed 24-hour partner response and 4-hour emergency injunction dispatch.
- **Accessible Reduced-Motion Alternative**: Full editorial magazine fallback for `prefers-reduced-motion: reduce`.
- **Dual-Tier Video Scrubbing**: Desktop (1080p/720p, GOP 8, faststart) and mobile (720p/540p, GOP 4, faststart).

## Tech Stack
- Vanilla HTML5 / CSS3 / JavaScript (Zero framework bloat)
- Scroll World Scrub Engine
- FFmpeg seamless seam & tight-GOP video pipeline
- Hosted on GitHub Pages
